================================================================================
                      WEBSITE WIREFRAME DRAWING
                 Accessible Three-Page Portfolio Blueprint
================================================================================

PROJECT SCOPE
- Three pages: Home, About, Projects.
- Shared structure: skip link, sticky header with navigation, main content, footer.
- About page includes an accessible contact form with labels, fieldsets, and error UI.

================================================================================
1. SITE MAP (NAVIGATION FLOW)
================================================================================

                    +-----------------------------------+
                    | SHARED HEADER / PRIMARY NAV       |
                    | Home | About | Projects           |
                    +-----------------------------------+
                          /            |            \
                         /             |             \
            +----------------+   +----------------+   +----------------+
            | HOME PAGE      |   | ABOUT PAGE     |   | PROJECTS PAGE  |
            | hero + cards   |   | bio + form     |   | project cards  |
            +----------------+   +----------------+   +----------------+

Navigation is available on all pages so users can jump directly to any section.

================================================================================
3. HOME PAGE WIREFRAME
================================================================================

- Hero: mission statement + CTA to projects.
- Focus panel: three highlight cards.
- Quote block.

Home content modules:
1) Hero headline and intro paragraph.
2) Three focus cards (accessible, architecture, consistency).
3) Supporting quote block.

================================================================================
4. ABOUT PAGE WIREFRAME (INCLUDES CONTACT FORM)
================================================================================

- Intro hero: personal background.
- Skills panel: card grid.
- Contact panel: accessible form.

Contact form structure:
1) Full Name input with label and inline error text.
2) Email input with label and inline error text.
3) Fieldset + legend for Preferred Service checkboxes.
4) Fieldset + legend for Project Budget radio options.
5) Message textarea with label and inline error text.
6) Error summary (role=alert) and submit button.
7) Success message area.

================================================================================
5. PROJECTS PAGE WIREFRAME
================================================================================

- Hero intro paragraph.
- Project showcase grid with 4 cards.
- Return CTA to About page.

Each project card:
1) Project title.
2) Tech stack line.
3) Short description.
4) Text link.

================================================================================
6. MOBILE ADAPTATION
================================================================================

- Header stacks naturally with wrapped nav links.
- Card grids collapse into one-column stack.
- Form controls remain full width for easier touch and readability.
- Spacing contracts to keep content legible on small screens.
